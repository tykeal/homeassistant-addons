# Captive Portal Guest Access

Guest Wi-Fi captive portal for Home Assistant.

Provides voucher-based and booking-based guest authentication integrated
with TP-Link Omada controllers. Features role-based admin access,
comprehensive audit logging, and Rental Control integration for
automatic guest access based on booking schedules.

For full documentation see the
[project repository](https://github.com/tykeal/homeassistant-captive-portal).
