# RentalSync Bridge

Multi-PMS booking sync and iCal export bridge for Home Assistant.

Syncs booking data from property management systems (Cloudbeds, Guesty)
and exports RFC 5545 compliant iCal feeds with room-level granularity.
Includes a web-based admin interface and automatic background sync.

For full documentation see the
[project repository](https://github.com/tykeal/homeassistant-rentalsync-bridge).
